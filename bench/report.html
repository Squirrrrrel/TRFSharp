Method notes

  • Both sides consume the same problems.json: identical x0, bounds, data matrices (base64 float64) and solver options.
  • Best-of-N wall clock of the whole solve; warm-up excluded. N = 9 for n·m ≤ 4 000, 5 for n·m ≤ 200 000, 3 otherwise.
  • TRF.Sharp is built Release; the bench host runs on the installed runtime (.NET 10.0.10) while the library targets net8.0.
  • SciPy ≥ 1.16 no longer exposes nit for method='trf'; it is read from the last callback, which carries the same counter.
